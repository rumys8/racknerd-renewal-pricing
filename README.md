## 续费价格到底涨不涨价

促销套餐不涨。这类套餐指活动页上那些年付 $21.99 起的方案，下单时价格就固定在账户里，续费时系统生成的账单金额和你第一次付款完全一致，也不用重新输入优惠码。能查到的续费账单都对得上：$11 出头买的 1 GB 续过两次没动，2023 年黑五 $35.99/年 的 2 GB 今年账单仍是 $35.99，还有 $11.29/年 的机器续了三年一分没涨。第三方测评站在核对官网 FAQ 时也记了这一条，原文写的是 lifetime recurring。

锁的是“你这个账户下、这个套餐、这个价格”，有三个边界值得说清楚：

- **按时续才锁得住。** 到期没付、服务被暂停，过一阵再想恢复，很可能已经算重新下单，按当时现价走。所谓永久锁价的前提是一直不断档。
- **套餐下架不影响老用户。** 活动页撤掉了，手里那台照原价续，续费入口还在。
- **条款理论上可以调整。** 服务商保留修改定价规则的权利，只是这些年没动过，而且锁价本身是它留住老用户的核心卖点。

续费同价只对促销套餐成立。标准套餐续费按官网届时标价走，不承诺锁价。

## 提前续费怎么操作

四步，两分钟能走完。

1. 登录客户中心，进 Services → My Services，找到那台机器。
2. 点进服务详情页。
3. 看**左侧的 Actions 列**，里面有 Generate Renewal Invoice，点它。
4. 系统生成下一周期的发票，点发票号进详情页，选支付方式付款。

第 3 步是唯一容易卡住的地方：这个按钮不在页面顶部那排大按钮里，第一次续费的人往往在顶上找半天。提前续费和等系统自动出账走的是同一条路，只是一个你主动触发，一个系统替你触发。

付完之后服务周期顺延一整年，原到期日 12 月 1 日就变成次年 12 月 1 日，不重叠计费，也不会因为付得早而缩短周期。

付款页面能选支付宝，也能用 PayPal 和信用卡，另外支持比特币。有资料提到可以先在 Billing → Add Funds 充余额，账单生成后系统从余额扣，省掉手动付款这一步，比如年付 $35.99 就充 $36。这条只有一处提及，没在官方文档里找到对应说明，当技巧试，别当保证。

## 续费前先做三件事

**整盘备份到本地。** 续费本身不出问题，出问题的是续费之后你才发现 IP 不能用了、或者想趁机换个机房，那时候没备份就很被动。

**查一下 IP 有没有被墙。** 购买后 72 小时内可以免费换一次，超过 72 小时每次 $3。顺序必须是先换 IP 再续费，反过来就成了续完再花钱换，多付一笔。有作者记录过续完才发现 IP 早就不能用的情形，钱白花了一年。

**确认当前机房还合不合适。** 续费锁定的是原机房，觉得当前节点延迟不理想，续费前开工单问迁移。能不能迁、要不要补钱，以工单答复为准，别把帖子里的说法当成必然。

## 忘了续费会怎样

不会立刻删数据。过期后一般有几天宽限期，宽限期内服务器可能已经停了、SSH 连不上，但磁盘上的数据通常还在。具体几天没有公开的固定数字，跟套餐和账户状态有关，而且随时可能被清理，越往后越没保障。

补救顺序是这样：

1. 登录后台，找到那张逾期的发票，付掉。
2. 多数情况付完会自动恢复。
3. 还是起不来，开工单说明情况，让人手动复机。
4. 数据已经被清掉，只能从自己的备份恢复。

有第三方记录提到过期三天才想起来、付完半小时恢复的例子，这种运气不能写进计划里。发票一直不付会怎样？它会挂在那儿，服务到期暂停，期间你随时可以回去付掉。

## 付款、退款和两个常见误会

退款政策比较硬：官方不提供退款，这条写在服务协议里，同时承诺会解决问题直到你满意。年付十几美元试错成本不算高，但买之前还是想清楚配置够不够，别指望用了不满意能退。

第一个误会是“要去关掉自动续费”。系统生成发票不等于自动扣款，本来就没有自动扣款这回事，没东西可关。真正要防的是提醒邮件被 Gmail 归到促销标签里，14 天通知没看见。把发件域名加进白名单，或者每隔一阵在邮箱搜一下 invoice。
